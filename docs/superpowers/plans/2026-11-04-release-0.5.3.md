# ClipBridge 0.5.3 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish verified Windows Setup/ZIP and persistent-certificate Android APK for version 0.5.3 through the existing GitHub Actions release workflow, after the approved narrow relaunch guard.

**Architecture:** A secondary launch used by the updater reports a distinct process exit code instead of looking like a failed new primary. The updater retains new files, staged files and backup without rollback or 100% completion when startup cannot be confirmed for that reason. Confirmed startup and genuine failed-startup rollback keep their existing behavior; signing, trust, URLs and install ACLs are unchanged.

**Tech Stack:** C# / WinForms / .NET SDK 10.0.403, isolated console smoke harness, PowerShell 7, Python unittest, Android SDK 36 / Java 17 / Gradle 8.11.1, GitHub Actions.

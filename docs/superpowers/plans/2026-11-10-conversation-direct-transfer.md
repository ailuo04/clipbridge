# 手动消息与原文件互传

用户后续明确要求替代剪贴板同步：文字手动粘贴编辑后发送，图片、视频和文件选择/拖入后作为附件发送；已配对设备自动接收。

已实现：
- Windows MessageComposer 接收手动粘贴；原文件路径不转换，剪贴板位图保存为无损 PNG（已有 PNG 编码时直接保留字节）；草稿按设备保留。
- 两端会话圆角消息、上下时间排序、底部编辑器、图片预览、文件进度。媒体预览与传输原文件分离。
- 移除 UI 的自动同步和读取对端剪贴板入口，收到文字只进入会话。
- 已认证设备直传，保留加密、逐文件大小和 SHA-256 校验、取消配对检查、不同名保存规则。
- 两端接收改为持续打开的缓冲输出流；避免每 64 KiB 开关一次文件。进度通知限制为每 100ms，终态立即通知。保持原有 64 KiB 协议兼容。
- Android 31+ 打开 content URI 时明确要求原始媒体格式；不调用图片重新编码或视频转码来发送。

验证：Windows 会话粘贴文字/图片、拖放、目标设备、失败保留附件、窄窗口、上下滚动；传输及历史测试；Android 单元测试和 debug 构建。局部 64MiB 磁盘接收基准包含哈希校验，不能代表 Wi-Fi 实际速度。

# 0.5.0 verification record

Date: 2026-11-02. All local checks ran without starting application windows, emulators, installers or browser previews. The OnePlus 15 was not connected or inspected.

- Windows application and both smoke-test projects compile. UI smoke tests are intentionally not executed. The update smoke-test project retains existing nullable-reference warnings in unchanged update code.
- Headless transfer tests cover legacy crypto, explicit clipboard sends, file integrity/cleanup/refusal, independent per-device sessions, dual pairing approval and refusal, unknown/forged discovery, wrong route targets/types and revocation.
- A real TCP regression reproduces and rejects a second peer reusing a live pairing Session ID. A separate gate test verifies that stale UI request objects and cleanup by another session cannot approve or remove the current request.
- A stalled-preface regression verifies that Windows releases both occupied file receiver slots after its handshake timeout and then accepts a legitimate authenticated transfer.
- C#/JVM interoperability runs the actual C# pairing server against production Kotlin crypto, compares the SAS, and transfers authenticated text and files in both directions. A separate test covers legacy file transfers in both directions. The tests use loopback sockets and synthetic identities/data only.
- Android tests verify signed update metadata, rejected signatures/URLs/package IDs/versions/certificates, payload size/hash corruption, signer identity checks and version-dependent LAN permission gating. Android unit tests and release lint/build pass. Toolchain update availability warnings reflect the pinned build versions.
- Publisher synthetic tests: 10 pass. Installer privilege/destination/update ACL policy check passes.
- APK release builds retain the fixed published certificate, package app.clipbridge, version 0.5.0 / versionCode 50000, and are non-debuggable. Windows ZIP/Setup and the combined RSA manifest pass size/hash/URL/signature checks.

Validation tools: tools/TransferTests, tools/Test-AndroidInterop.ps1, Android Gradle unit tests/lint, tools/Build-AndroidRelease.ps1, tools/Publish-GitHub.ps1, tools/Verify-Release.ps1 and tools/Test-InstallerPolicy.ps1. The interoperability check is now part of the release workflow so later releases repeat it.

Limits: no real OnePlus/ColorOS, Android system installer, interactive UI, physical Wi-Fi/hotspot/firewall, or 1 GiB phone transfer test has been performed. Current Android minSdk=29 and compile/target=36. API 37+ LAN permission gating is prepared for a future target SDK increase; unknown future Android versions still require validation and adaptation.

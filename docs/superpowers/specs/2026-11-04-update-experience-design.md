# Windows 更新体验

使用现有 WinForms 和 Ui 调色板实现独立液态玻璃更新窗口。确认版本和说明、下载、校验、解压、安装和启动都在同一视觉系统中呈现，浅色和深色主题保持一致。

下载显示真实字节数、速度和剩余时间；总进度按下载 0–80%、校验 80–82%、解压 82–90%、安装 90–98%、启动 99–100% 分段，100% 只在新版确认启动后显示。网络与磁盘操作不阻塞 UI。下载/解压支持取消；替换文件期间禁止取消。错误保留可读原因和重试入口。

安装助手独立显示进度，等待旧进程退出、备份并替换文件后以 --updated 启动新版。新版显示主界面并通知命名事件，助手收到通知后才删除备份。启动失败恢复备份并尝试打开原版。保持现有 RSA、SHA-256、大小和 HTTPS 校验，不修改密钥、版本号和发布内容。

测试使用隔离临时目录和回环 HTTP 服务，覆盖下载进度、取消、校验失败、解压取消、安装进度、启动确认和失败回滚；UI 烟测覆盖浅深色、取消/重试、安装防误关、DPI、布局和截图。

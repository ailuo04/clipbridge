# ClipBridge 单窗口多设备会话设计

状态：规划稿；本轮仅设计，尚未实施。

## 用户目标
把现有主界面的设备区域替换为实际对话区。左侧改为设备和功能目录，不再显示密钥操作、网络配置卡、运行记录。局域网设备配对后直接收发文字、原始图片、视频和文件。允许多设备会话切换，更新入口也放在左侧。

## 推荐结构与取舍
采用一个主窗口、一个左侧栏、一个右侧内容区。保留现有独立聊天窗口仅做入口转接，最终不再维护两个聊天宿主。相比继续弹出聊天窗口，该结构有唯一当前设备；相比增加第三列，适合当前自用设备数量且保留更多图片和消息空间。

左栏建议逻辑宽度 240–280，随 DPI 缩放；右侧占剩余空间。窗口变窄时减少侧栏宽度及预览文字，保留设备名称和未读标识。沿用当前浅色、深色、跟随系统主题。避免嵌套多层大卡片与重复大标题。

左侧自上而下：
- 应用标识及本机名称。
- 添加设备固定入口。
- 可滚动设备会话列表：设备图标、名称、在线状态、最新消息摘要、未读数；草稿和传输中状态可见。
- 底部固定入口：接收文件夹、设置、检查更新；版本信息紧凑显示。

右侧选择设备时：
- 顶部当前设备名称与在线状态，更多菜单包含重命名、设备详情、取消配对。
- 中间左右消息气泡；图片预览、视频入口、文件卡片及传输进度。
- 底部附件工具、待发送预览、文本编辑器、发送按钮。
- 删除顶部设备下拉框与重复设备管理按钮，切换设备统一在左侧。

## 导航与连接
启动时恢复上次选择的仍有效设备。不存在时选择最近会话；完全没有设备时显示添加设备引导。已配对但离线设备仍留在列表，允许看历史、编辑草稿；发送按钮明确显示离线状态，不宣称支持离线投递。

添加设备在右侧内容区打开附近设备和配对二维码，手动 IP 放入折叠的备用入口。配对成功后加入左侧并进入对话。刷新发现不清空现有会话、不改变当前选择。收到其它设备消息只增加未读和摘要，不强制跳转或抢焦点。

设置和更新页面也复用右侧内容区。离开会话不会丢失文本、附件或停止传输。更新安装入口在有活动传输时给出明确状态，待传输结束再进入安装，避免重启中断文件。

## 多会话状态
以稳定的 PeerId 为键，不能以 IP 或列表位置为键。设备地址变化只更新路由。每个设备单独维护文本草稿、附件、滚动位置、未读状态及发送状态；切换后立即还原。重启时至少恢复选择设备与未读边界，历史继续遵循现有 7 天保留规则；本轮不扩展为永久聊天备份。

发送操作开始时捕获 PeerId、附件快照与消息内容。异步完成只更新该设备的状态，不能清空当前另一设备的草稿。会话切换始终可用；给 A 传文件时可以给 B 发文字。大文件任务采用有界队列，避免无限并发争抢磁盘和网络；排队中与传输中状态必须区分，不在此承诺多设备同时满速。

文字发送也应核对认证会话的目标 PeerId，与文件的 expectedPeerId 保护一致。取消配对后终止相关活动任务，清除该设备待发送队列；本地已接收文件不删除。取消配对与清除聊天记录是两个独立操作。

## 保留与移除
主界面移除密钥显示、复制/修改密钥入口、运行日志列表、常驻手动 IP 输入和旧自动同步开关。内部配对身份、传输加密、原文件大小及 SHA-256 校验继续保留。后台诊断可保留，不作为日常界面区域。

图片和视频沿用原文件传输，不转码、不压缩；缩略图只用于展示。剪贴板位图以无损 PNG 发送；原始编码和元数据要求用原文件选择/拖入路径。已配对设备免二次接收确认。

自动更新签名、公钥、下载来源与发布流程保持现有约定；不在此任务发布或覆盖安装。

## 代码整合方向
- ControlPanelForm：作为唯一窗口宿主，替换 BuildNetwork/BuildEvents/BuildDevices 的主布局为侧栏及内容宿主。
- ConversationForm：将消息列表、编辑器、附件区提取为可嵌入 ConversationView；窗口生命周期与会话状态分离。
- 新增按 PeerId 管理的 ConversationSessionStore；UI 控件不持有跨会话发送生命周期。
- TrayAppContext：统一托盘、配对成功、文件发送入口到主窗口的指定会话，取消自动弹出第二个聊天窗口。
- 会话列表合并持久配对设备与发现状态；不能仅由在线 GetPeerSnapshots 构建，否则离线设备会消失。
- DevicesForm：提取可嵌入设备添加内容，保留现有配对流程，避免简单嵌套顶层 Form。
- 更新流程继续使用现有服务，入口移至侧栏；主题切换仍更新同一窗口。

本次截图对应 Windows，先完成桌面结构。Android 保持兼容，后续可用手机会话列表→点入聊天的导航，不强行照搬桌面固定侧栏。

## 实施顺序
1. 提取会话内容控件与会话状态，维持原收发行为。
2. 建立侧栏和设备列表，把聊天区嵌入主窗口。
3. 接入添加设备、设置、更新及托盘路由；移除旧主界面区域。
4. 完成未读、独立草稿、离线记录与传输时切换，验证所有异步回调归属。
5. 运行回归测试，生成真实窗口截图，提供独立预览构建。

## 验收
- 无设备、单设备、多设备、离线设备四种状态均可理解和操作。
- 点击左侧设备切换对应历史，刷新和新消息不会错误切换会话。
- A 草稿含文字和附件，切 B 再回 A 完整保留。
- 给 A 传文件期间切 B 发消息，目标正确，A 完成不改动 B 草稿。
- 失败和取消均归属正确会话，重试不会重发已经成功发送的文字。
- 未读只在实际查看对应会话时清除；查看旧历史时新消息不强制滚动到底部。
- 不出现密钥卡片、运行日志、重复设备下拉框或第二个聊天窗口。
- 文件选择、粘贴、拖入、原文件完整性测试继续通过。
- 更新/添加设备/主题切换保留会话状态；窄窗口和高 DPI 无遮挡。
- Windows 构建、UI smoke、传输/历史测试通过；真机网络与安装验证单独报告。
